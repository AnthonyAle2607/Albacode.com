# AlbaCode.com

Sitio web de AlbaCode, preparado para desplegarse en Vercel como una landing page estática.

## Desarrollo local

```bash
npm install
npm run dev
```

## Despliegue en Vercel

1. Conecta este repositorio a Vercel.
2. Usa la configuración por defecto para un proyecto estático.
3. Vercel detectará `index.html` y lo publicará automáticamente.

## Archivos principales

- `index.html`: landing page principal
- `vercel.json`: configuración para URLs limpias
- `package.json`: scripts locales de arranque
